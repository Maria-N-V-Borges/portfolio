# 💻 Maria's Portfolio

> Personal portfolio website showcasing my journey as a Computer Science student, developer, and creative learner.

## 📌 About the Project

This is my personal portfolio website, created to showcase my skills, projects, education, and experiences as I grow in the field of technology.

The website was built from scratch using HTML5, CSS3, and JavaScript, with a focus on creating a clean, responsive, and visually engaging experience.

The design combines my interests in programming, game development, web development, and digital art.
